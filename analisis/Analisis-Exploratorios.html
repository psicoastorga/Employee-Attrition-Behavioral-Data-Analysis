Eliminación de variables constantes EmployeeCount (Cantidad_empleados), Over18 (Mayor 18) y StandardHours.

datos <- datos[, !names(datos) %in% c("cantidad_empleados", "mayor_18", "horas_estandar")]

Elimina la variable EmployeeNumber (numero_empleado) por tener valores arbitrarios.

datos <- datos[, !names(datos) %in% "numero_empleado"]

Crear una variable variables_numericas la cual es una lista que contiene todas las variables inter y numeric de datos

variables_numericas <- names(datos)[sapply(datos, is.numeric)]

Crear una variable variables_no_numericas la cual es una lista que contiene todas las variables char y no numericas

variables_no_numericas <- names(datos)[!sapply(datos, is.numeric)]
